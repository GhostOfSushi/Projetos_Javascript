# Exemplos de JavaScript

Coleção de quatro pequenos projetos feitos com **HTML, CSS e JavaScript puro**, reunidos em uma página principal que dá acesso a cada exemplo.

🔗 **Ver online:** [https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/](https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/)

## Exemplos

| # | Projeto | O que faz | Conceitos praticados |
|---|---------|-----------|----------------------|
| 1 | [Gerador de Tabuada](exemplo1.html) | Calcula a tabuada de um número até um limite e lista os resultados pares | Validação de entradas, laços `for`, geração de HTML dinâmico |
| 2 | [Gerador de Senhas](exemplo2.html) | Cria senhas com tamanho e tipos de caracteres configuráveis, avalia a força e copia ao clicar | `crypto.getRandomValues`, arrays, Clipboard API |
| 3 | [Simulador de Publicação](exemplo3.html) | Campo de texto com limite de 140 caracteres, contador de palavras e barra de progresso | Eventos `input`, manipulação do DOM, estado do botão |
| 4 | [Lista de Mercado](exemplo4.html) | Adiciona, marca e remove itens, mantendo a lista salva | `localStorage`, `JSON`, renderização de listas |

## Como executar

Não é preciso instalar nada.

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
   ```
2. Abra o arquivo `index.html` no navegador (clique duas vezes ou use a extensão *Live Server* do VS Code).
3. Escolha um exemplo na página principal.

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)

## Publicar no GitHub Pages

1. No repositório, abra **Settings → Pages**.
2. Em **Branch**, escolha `main` e a pasta `/ (root)`.
3. Salve e aguarde o link ser gerado.
